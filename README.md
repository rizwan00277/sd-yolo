# SD-YOLO project page

Static page for GitHub Pages, built on the
[Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## How to put this page online (no commands needed)

1. **Unzip** `webpage_sd_yolo.zip` on your computer.
2. On github.com click **New repository**. Name it, for example, `sd-yolo`, and set it to
   **Public** (GitHub Pages on a free account works only for public repositories).
   Do not add a README, .gitignore, or license; leave the repository empty.
3. In the new repository click **uploading an existing file**.
4. Open the unzipped folder, select **everything inside it** (`index.html`, `README.md`,
   `static/`, and the rest), and drag it onto the upload page. Drag the contents, not the
   folder itself, so that `index.html` sits at the top level of the repository.
   Click **Commit changes**. (Limits: 25 MB per file and 100 files per upload; the
   largest file here is about 12 MB and there are about 60 files.)
5. Go to **Settings → Pages → Build and deployment**. Set **Source** to
   "Deploy from a branch", branch **main**, folder **/ (root)**, then click **Save**.
6. After one or two minutes the page is live at
   `https://<your-username>.github.io/sd-yolo/`.
   The link also appears at the top of **Settings → Pages**.

### Check after uploading

- Open the page and play a few videos in the "Tracking Videos" section, and check that the
  figures load. If videos or images are missing, the `static/...` folders were flattened
  during upload: the repository must contain `static/videos/`, `static/images/`, and so on,
  exactly as in the zip.
- The hidden file `.nojekyll` may be skipped by drag-and-drop on a Mac. That is fine; the
  page works without it.

### If drag-and-drop does not keep the folders

Use **GitHub Desktop** (File → Add local repository → choose the unzipped folder →
Publish repository, untick "Keep this code private"), or run these commands inside the
unzipped folder:

    git init
    git add .
    git commit -m "Project page"
    git branch -M main
    git remote add origin https://github.com/<your-username>/sd-yolo.git
    git push -u origin main

Then do step 5 above.

## Preview locally

    python3 -m http.server 8000    # inside this folder, then open http://localhost:8000

## Updating the page later

- Text (title, authors, abstract, results table, BibTeX) is in `index.html`.
- When the paper is published, enable the "Paper" and "Code" buttons in `index.html`
  (they are disabled placeholders now: replace the `disabled` link with an `href`) and
  change the BibTeX `journal` field from "Under review" to the journal name.
- To change a file on GitHub, open it in the repository and click the pencil icon, or
  upload the new version with **Add file → Upload files**. The page updates within a minute or two.

## Contents

- `index.html`: page text and layout.
- `static/videos/`: 2×3 comparison clips (H.264, at most 40 s, about 48 MB in total);
  `static/posters/`: preview frames.
- `static/js/videos.js`: video list and tracking F1, generated by
  `codes/make_webpage_data_20261015.py` in the project repository.
- `static/js/gallery.js`, `static/css/custom.css`: video gallery and styling added to the template.
- `static/images/`: paper figures.
